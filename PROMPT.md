# Setup Prompt
Implementa una estructura minimal base, de contenido html estático, semántico y jerárquico usando la librería lenis.js.

- La primer pantalla debe ser un preloader que le pida al usuario una foto de perfil o foto de cámara, y luego podrá avanzar a la navegación. 
- La navegación consta de un OnePage de 5 secciones, con elementos dentro de que disparen diferentes triggers en movimiento en 'y'.

Para javascript ocupa ES5, no ocupes estilos inline, todo el css tiene que ser minimalista, sólo estilo bases aplicando propiedades mediante tokens dentro de style.css
